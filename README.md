# FABBEYOND.DEV

[fabbeyond.dev](https://www.fabbeyond.dev) is my personal portfolio Website which includes all my projects, skills and general history about my programming journey.

It's made with Astro, which has the React component structure but exports to static HTML which is perfect for websites like these.

# Building

Firstly install the dependencies using `npm install`
Then run `npm run dev` to have a local live updating version or `npm run build` to build to static HTML.
